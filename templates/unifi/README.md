# Template UniFI

Materiale fornito per l'elaborato e la presentazione della laurea triennale
in Ingegneria Informatica presso la Scuola di Ingegneria dell'Università
degli Studi di Firenze.

## Contenuto

- `presentazione_16_9.pptx`: template PowerPoint UniFI in formato 16:9,
  composto da 10 layout di esempio;
- `originali/Template_tesi.zip`: archivio originale ricevuto;
- `tesi_latex/`: soli sorgenti utili estratti dall'archivio, senza i vecchi
  file temporanei di compilazione.

## Nota sul template LaTeX

Il pacchetto ricevuto è datato 2018 e la classe `Tptesi2.cls` deriva da una
classe più vecchia. Va quindi usato come base grafica e di frontespizio,
aggiornando con cautela i pacchetti obsoleti prima della stesura definitiva.
L'originale ZIP resta immutato come riferimento.
